# politractor

Politractor — Optimitzador de Càrrega de Contenidor 40' HC
Eina web per optimitzar la distribució de màquines dins d'un contenidor marítim de 40 peus High Cube.

Què fa
Calcula la millor disposició 3D de màquines dins el contenidor
Algorisme genètic (80 individus × 300 generacions) per trobar la distribució òptima
Funció de maximització automàtica de quantitats per model
Visualització 2D de planta (vista de dalt) i costat
Importació directa des d'Excel/Google Sheets (Ctrl+V)
Control de pes màxim (GW)
100% offline — s'executa al navegador sense servidor ni connexió
Paràmetres del contenidor
Configurables: longitud, amplada, alçada (mm) i pes màxim (kg).
Per defecte: 12.000 × 2.350 × 2.695 mm · 26.000 kg GW

Com usar-ho
Obre la URL
Afegeix les màquines (manualment o enganxant des d'Excel)
Ajusta les quantitats amb +/−
Clic Calcular Optimització o Calcular Quantitats Màximes
